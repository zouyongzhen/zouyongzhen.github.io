1. 概要と範囲

Mistwick Vigil は、オフラインのコア ゲームプレイ向けに設計されたシングルプレイヤー ゲームです。開発者はアプリの責任者であり、連絡先 セクションの電子メール アドレスを使用して連絡できます。

このポリシーは、Mistwick Vigil Android アプリとこの Web サイトのゲーム固有のページに適用されます。現在のバージョンについて説明します。ストア、電子メール アプリケーション、ブラウザーからリンクされている無関係なアプリや Web サイトは対象外です。

簡単に言うと: このアプリにはアカウント システム、広告、行動分析、アプリ内購入がありません。ゲームプレイの設定と進行状況はローカルに保存されます。当社は、セーブデータを受け取るゲームプレイサーバーを運営していません。

2. デバイスに保存されている情報

エクスペリエンスを復元するために、アプリは次の情報をローカル アプリケーション ストレージに保存する場合があります。

  • 選択したインターフェース言語、オーディオレベル、サウンド設定、コントロール、および表示設定。
  • 選択したウォッチキーパーとルート、ロック解除されたルートまたは役割、最高の結果、およびその他のサポートされているゲームの進行状況。
  • アプリ内開示および法的文書のバージョンまたは承認状態。アプリはそれらを記録します。

この情報は、ローカル アプリの機能を提供および復元するためにのみ使用されます。これはリモート アカウント プロファイルではありません。現在のゲームでは、名前、正確な場所、連絡先、写真、支払いの詳細の提供は求められません。

3. 初期のデバイス言語の選択

初回起動時に、アプリは Android によって提供される言語設定を読み取り、サポートされているインターフェイス言語を選択します。優先言語がサポートされていない場合、アプリでは英語が使用されます。言語を手動で選択すると、その選択はローカルに保存され、後の起動時に優先されます。

言語設定はインターフェイスの表示に使用され、コア ゲームからは送信されません。

4. ネットワークの使用とリモートの法的ページ

主要なゲームプレイにはインターネット接続は必要ありません。アプリ内のプライバシー ポリシーと規約のリンクは、GitHub Pages でホストされているページを指しているため、これらのページはインターネット接続が必要であり、デバイスまたはホスティング サービスがオフラインの場合は利用できない可能性があります。

リモートの法的ページを開くことを選択すると、ブラウザまたは WebView は GitHub Pages に対して標準の Web リクエストを作成します。 GitHub は、サービスを提供および保護するために、IP アドレス、要求された URL、タイムスタンプ、ブラウザまたはデバイスのヘッダーなどの技術的な接続情報を処理する場合があります。アプリはこれらのリンクにセーブデータを追加しません。

この Web サイトは、広告、分析スクリプト、追跡ピクセル、または当社が設定した Cookie を使用しません。ブラウザー、ネットワーク プロバイダー、GitHub ページには独自のデータ プラクティスがあります。

5. サードパーティのサービスと外部リンク

現在のアプリには、広告ネットワーク、行動分析プロバイダー、支払い処理業者、ソーシャル ログイン サービス、開発者が運営するゲームプレイ バックエンドは統合されていません。

GitHub Pages は、この Web サイトとその法的文書をホストしています。アプリ ストアは、ユーザーがアプリを閲覧、ダウンロード、インストール、または更新するときに、独自のプライバシー規約に基づいて情報を処理する場合があります。電子メール リンクを選択した場合、電子メール アプリケーションとプロバイダーがメッセージとその内容を処理します。

開発者は個人情報を販売またはレンタルしません。広告や行動プロファイリングを目的として、コア ゲームによって開発者または第三者と個人情報が共有されることはありません。

6. 保存と削除

Android 設定でアプリのストレージをクリアするか、アプリをアンインストールするまで、ローカル設定と進行状況はデバイスに残ります。どちらのアクションでも、ローカルに保存されているアプリの設定、ロック解除、結果、進行状況が削除されます。保存しておきたい場合は、デバイスまたはアプリ ストアで提供されているものを個別にバックアップしてください。ゲーム自体はクラウド セーブ同期を提供しません。

アプリの終了時に、アクティブなウォッチは開発者サーバーにアップロードされません。 GitHub、アプリ ストア、または電子メール プロバイダーによって独自に処理された情報は、そのプロバイダーのポリシーに従って保持されます。

7. セキュリティ

ゲームプレイ データをアプリのローカル ストレージに保存すると、データを送信する必要性が減ります。リモートの法的ページは HTTPS 経由で提供されます。完全に安全な保存方法や送信方法はないため、デバイスとオペレーティング システムを常に最新の状態に保ち、デバイスで利用可能なアクセス保護を使用してください。

8. 子供のプライバシー

現在のアプリは、アカウント登録、広告、分析、ゲームプレイ サーバーを通じて、意図的に子供から個人情報を収集することはありません。親および保護者は、必要に応じて、お子様によるリモート Web リンクおよび電子メールの使用を監督する必要があります。個人情報が不必要に当社に送信されたと思われる場合は、当社にご連絡ください。当社が個人情報を確認し、必要に応じて当社自身の記録から削除します。

9. お客様の選択とプライバシーの権利

Android のコントロールを使用して、アカウントを作成せずにコア ゲームをプレイしたり、アプリのインターフェイス言語を変更したり、リモート ページや電子メール リンクを開かないようにしたり、ローカル データを削除したりできます。

適用される法律によっては、サポート電子メールなど、お客様が自発的に当社に送信した個人情報に関する権利を有する場合があります。お客様は、法的保存義務および検証の必要性を条件として、当社自身の記録内の情報へのアクセス、修正、または削除をリクエストするために当社に連絡することができます。プラットフォームまたは GitHub が保持する情報には、関連するプロバイダーを通じて対処する必要があります。

10. 本ポリシーの変更

アプリの機能、ホスティング、またはデータ慣行が変更された場合、当社はこのポリシーを更新することがあります。上部にあるドキュメントのバージョンと発効日は、現在のテキストを示しています。重要な変更は、必要に応じてアプリまたはこの Web サイトに表示されます。適用法により別の形式の通知または同意が必要な場合を除き、更新後の継続使用には、改訂されたポリシーが適用されます。
