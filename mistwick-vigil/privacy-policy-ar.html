1. نظرة عامة ونطاق التطبيق

Mistwick Vigil لعبة فردية صُممت ليعمل لعبها الأساسي دون اتصال بالإنترنت. المطوّر هو الشخص المسؤول عن التطبيق، ويمكن التواصل معه باستخدام عنوان البريد الإلكتروني الوارد في قسم التواصل.

تنطبق هذه السياسة على تطبيق Mistwick Vigil لنظام Android وعلى الصفحات الخاصة باللعبة في هذا الموقع الإلكتروني. وهي تصف الإصدار الحالي؛ ولا تشمل التطبيقات أو المواقع الإلكترونية غير ذات الصلة التي ترتبط بها متاجر التطبيقات أو تطبيقات البريد الإلكتروني أو متصفحك.

باختصار: لا يتضمن التطبيق نظام حسابات أو إعلانات أو تحليلات سلوكية أو عمليات شراء داخل التطبيق. تُخزن إعدادات اللعب والتقدم محليًا. ولا نشغّل خادمًا للّعب يتلقى بيانات حفظك.

2. المعلومات المخزنة على جهازك

لاستعادة تجربتك، قد يخزن التطبيق المعلومات التالية في مساحة تخزينه المحلية:

  • لغة الواجهة التي اخترتها، ومستويات الصوت، وإعدادات الصوت، وعناصر التحكم، وتفضيلات العرض.
  • الحارس والمسار اللذان اخترتهما، والمسارات أو الأدوار التي فتحتها، وأفضل النتائج، وغير ذلك من التقدم المدعوم في اللعبة.
  • إصدارات الإفصاحات والمستندات القانونية داخل التطبيق أو حالة الإقرار بها، حيثما يسجلها التطبيق.

تُستخدم هذه المعلومات فقط لتوفير وظائف التطبيق المحلية واستعادتها. وهي ليست ملفًا شخصيًا لحساب بعيد. لا تطلب منك اللعبة الحالية تقديم اسمك أو موقعك الدقيق أو جهات اتصالك أو صورك أو بيانات الدفع الخاصة بك.

3. اختيار لغة الجهاز الأولية

عند التشغيل الأول، يقرأ التطبيق تفضيلات اللغة التي يوفرها Android لاختيار لغة واجهة مدعومة. إذا لم تكن لغتك المفضلة مدعومة، يستخدم التطبيق الإنجليزية. وبمجرد اختيار لغة يدويًا، يُحفظ اختيارك محليًا ويحظى بالأولوية عند مرات التشغيل اللاحقة.

يُستخدم تفضيل اللغة لعرض الواجهة، ولا ينقله اللعب الأساسي إلينا.

4. استخدام الشبكة والصفحات القانونية المستضافة عن بُعد

لا يتطلب اللعب الأساسي اتصالًا بالإنترنت. تشير روابط سياسة الخصوصية والشروط داخل التطبيق إلى صفحات مستضافة على GitHub Pages، لذا تحتاج هذه الصفحات إلى اتصال بالإنترنت وقد لا تكون متاحة إذا كان جهازك أو خدمة الاستضافة غير متصل بالإنترنت.

عندما تختار فتح صفحة قانونية مستضافة عن بُعد، يرسل متصفحك أو WebView طلب ويب اعتياديًا إلى GitHub Pages. وقد يعالج GitHub معلومات الاتصال التقنية، مثل عنوان IP الخاص بك وعنوان URL المطلوب والطابع الزمني وترويسات المتصفح أو الجهاز، لتقديم خدمته وحمايتها. لا يضيف التطبيق بيانات حفظك إلى هذه الروابط.

لا يستخدم هذا الموقع الإلكتروني إعلانات أو نصوص تحليلات برمجية أو وحدات بكسل للتتبع أو ملفات تعريف ارتباط نضعها نحن. ولمتصفحك ومزود الشبكة وGitHub Pages ممارسات بيانات خاصة بهم.

5. خدمات الجهات الخارجية والروابط الخارجية

لا ندمج في التطبيق الحالي شبكات إعلانية أو مزودي تحليلات سلوكية أو معالجي مدفوعات أو خدمات تسجيل دخول عبر الشبكات الاجتماعية أو خادمًا خلفيًا للّعب يشغّله المطوّر.

تستضيف GitHub Pages هذا الموقع الإلكتروني ومستنداته القانونية. وقد يعالج متجر التطبيقات معلومات عندما تتصفح التطبيق أو تنزّله أو تثبته أو تحدّثه وفقًا لشروط الخصوصية الخاصة به. وإذا اخترت رابط بريد إلكتروني، فإن تطبيق البريد الإلكتروني ومزود الخدمة يعالجان الرسالة ومحتوياتها.

لا يبيع المطوّر المعلومات الشخصية ولا يؤجرها. ولا يشارك اللعب الأساسي أي معلومات شخصية مع المطوّر أو جهات خارجية لأغراض الإعلان أو إنشاء ملفات تعريف سلوكية.

6. الاحتفاظ بالبيانات وحذفها

تبقى الإعدادات والتقدم المحليان على جهازك إلى أن تمسح بيانات التطبيق من إعدادات Android أو تلغي تثبيته. يؤدي أي من الإجراءين إلى حذف إعدادات التطبيق المخزنة محليًا والعناصر المفتوحة والنتائج والتقدم. انسخ احتياطيًا أي شيء يوفره جهازك أو متجر التطبيقات بصورة منفصلة إذا كنت تريد الاحتفاظ به؛ فاللعبة نفسها لا توفر مزامنة الحفظ مع السحابة.

لا تُرفع نوبة الحراسة الجارية إلى خادم للمطوّر عند الخروج من التطبيق. وتُحتفظ بالمعلومات التي يعالجها GitHub أو متجر التطبيقات أو مزود بريدك الإلكتروني بصورة مستقلة وفقًا لسياسات المزود المعني.

7. الأمان

يقلل الاحتفاظ ببيانات اللعب في مساحة التخزين المحلية للتطبيق من الحاجة إلى نقلها. وتُقدّم الصفحات القانونية المستضافة عن بُعد عبر HTTPS. لا توجد وسيلة تخزين أو نقل آمنة تمامًا، لذا حافظ على تحديث جهازك ونظام تشغيله واستخدم وسائل حماية الوصول المتاحة في الجهاز.

8. خصوصية الأطفال

لا يجمع التطبيق الحالي عن علم معلومات شخصية من الأطفال عبر تسجيل الحسابات أو الإعلانات أو التحليلات أو خادم للّعب. وينبغي للآباء وأولياء الأمور الإشراف على استخدام الطفل لروابط الويب البعيدة والبريد الإلكتروني عند الاقتضاء. إذا كنت تعتقد أن معلومات شخصية أُرسلت إلينا دون ضرورة، فتواصل معنا لنراجعها ونحذفها من سجلاتنا الخاصة حيثما يلزم.

9. خياراتك وحقوق الخصوصية

يمكنك لعب اللعبة الأساسية دون إنشاء حساب، وتغيير لغة الواجهة في التطبيق، وتجنب فتح الصفحات البعيدة أو روابط البريد الإلكتروني، وحذف البيانات المحلية باستخدام عناصر التحكم في Android.

بحسب القانون المعمول به، قد تكون لك حقوق تتعلق بالمعلومات الشخصية التي أرسلتها إلينا طوعًا، مثل رسالة بريد إلكتروني إلى الدعم. يمكنك التواصل معنا لطلب الوصول إلى المعلومات الموجودة في سجلاتنا الخاصة أو تصحيحها أو حذفها، مع مراعاة التزامات الاحتفاظ القانونية ومتطلبات التحقق. أما المعلومات التي تحتفظ بها المنصة أو GitHub، فيجب التعامل بشأنها عبر المزود المعني.
