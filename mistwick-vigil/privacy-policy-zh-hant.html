隱私政策

本政策說明目前版本《霧燈行》在裝置上保存哪些資訊、如何選擇初始語言，以及開啟遠端託管頁面時會發生什麼。

文件版本 1.1生效日期 2026 年 11 月 23 日適用於 Android 應用程式與本網站
本頁目錄概述與範圍本機資料裝置語言網路與協定頁面第三方服務保留與刪除資料安全未成年人選擇與權利政策更新聯絡我們

一、概述與適用範圍

《霧燈行》是一款以核心玩法離線運行為目標的單人遊戲。開發者負責本應用，你可以透過聯絡我們一節中的郵箱與開發者聯繫。

本政策適用於《霧燈行》Android 應用程式以及本網站中與遊戲相關的頁面，描述目前版本的資料處理方式。應用程式商店、郵件應用程式或瀏覽器中連結的其他無關應用程式和網站不在本政策範圍內。

簡而言之：應用程式沒有帳號體系、廣告、行為分析或應用程式內購。遊戲設定與進度保存在本機，我們沒有接收存檔資料的遊戲伺服器。

二、保存在裝置上的信息

為了恢復你的遊戲體驗，應用程式可能在本機應用程式儲存中保存以下資訊：

  • 所選介面語言、音量、音效、操作方式和顯示偏好。
  • 所選守夜人與路線、路線或職業解鎖狀態、最佳成績以及其他已支援的遊戲進度。
  • 在套用記錄該狀態時，已閱讀揭露的版本或確認狀態。

這些資訊僅用於提供和恢復本機應用程式功能，不構成遠端帳號畫像。目前遊戲不會要求你提供姓名、精確位置、通訊錄、照片或付款資訊。

三、初始裝置語言選擇

首次啟動時，應用程式會讀取 Android 提供的語言偏好，以選擇已支援的介面語言。如果首選語言不受支持，應用程式會使用英文。手動選擇語言後，該選擇會儲存在本機，並在後續啟動時優先使用。

語言偏好用於介面展示，核心遊戲不會將該偏好傳輸給開發者。

四、網路使用與遠端協定頁面

核心玩法不需要網路連線。應用程式內的隱私政策和服務協議連結指向 GitHub Pages 託管的頁面，開啟這些頁面需要網路；裝置或託管服務離線時，頁面可能無法存取。

當你主動開啟遠端協定頁面時，瀏覽器或 WebView 會向 GitHub Pages 發出標準網頁請求。 GitHub 可能為提供和保護服務而處理技術連接訊息，例如 IP 位址、請求的網址、時間以及瀏覽器或裝置請求頭。應用程式不會把你的存檔資料附加到這些連結中。

本網站不使用廣告、分析腳本、追蹤像素，也不會設定由我們控制的 Cookie。你的瀏覽器、網路服務提供者和 GitHub Pages 有各自的資料處理規則。

五、第三方服務與外部鏈接

目前應用程式未整合廣告網路、行為分析服務、支付處理方、社群登入服務或由開發者營運的遊戲後端。

GitHub Pages 託管本網站及協議文件。應用程式商店可能會依據其隱私規則處理你瀏覽、下載、安裝或更新應用程式時的資訊。當你選擇郵箱連結時，郵件應用程式及其服務提供者會處理郵件及其中內容。

開發者不出售或出租個人資訊。核心遊戲不會出於廣告或行為畫像目的，向開發者或第三方分享個人資訊。

六、保留與刪除

本機設定與進度會保留在裝置上，直到你在 Android 設定中清除應用程式儲存或解除安裝應用程式。上述操作會刪除套用本機儲存的設定、解鎖狀態、成績與進度。如需保留裝置或應用程式商店另行提供的備份，請自行確認；遊戲本身不提供雲端存檔同步。

當應用程式退出時，正在進行的巡夜不會上傳到開發者伺服器。 GitHub、應用程式商店或郵件服務提供者獨立處理的信息，並依照相應服務提供者的規則保留。

七、資料安全

將遊戲資料保存在應用程式本機儲存中，可以減少傳輸這些資料的需要。遠端協定頁面透過 HTTPS 提供。任何儲存或傳輸方式都無法保證絕對安全，請及時更新裝置和作業系統，並使用裝置提供的存取保護功能。

八、未成年人隱私

目前應用程式不會透過帳號註冊、廣告、分析或遊戲伺服器，故意收集未成年人的個人資訊。家長或監護人應在適當情況下指導未成年人使用遠端網頁連結和郵件功能。如果你認為有人向開發者發送了不必要的個人訊息，請聯絡我們，以便核查並在法律要求時從我們自己的記錄中刪除。

九、你的選擇與隱私權權利

你無需創建帳號即可體驗核心遊戲，可以在應用程式內更改介面語言，可以不打開遠端頁面或郵件鏈接，也可以透過 Android 的系統控制刪除本機資料。

根據適用法律，對於你主動發送給我們的個人資訊（例如支援郵件），你可能享有相應權利。你可以聯絡我們，請求存取、更正或刪除我們自己記錄中的信息，但需遵守法定保留義務並完成必要的身份核驗。平台或 GitHub 持有的信息，請透過相應服務提供者處理。

十、本政策的更新

當應用程式功能、託管方式或資料處理方式變更時，我們可能會更新本政策。頁面頂部的文檔版本與生效日期代表目前文字。涉及重要變更時，我們會在應用程式或本網站的適當位置進行說明。更新後繼續使用，適用修訂後的政策；適用法律要求其他通知或同意方式的除外。
