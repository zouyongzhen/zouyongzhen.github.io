隐私政策

本政策说明当前版本《雾灯行》在设备上保存哪些信息、如何选择初始语言，以及打开远程托管页面时会发生什么。

一、概述与适用范围

《雾灯行》是一款以核心玩法离线运行为目标的单人游戏。开发者负责本应用，你可以通过联系我们一节中的邮箱与开发者联系。

本政策适用于《雾灯行》Android 应用以及本网站中与游戏相关的页面，描述当前版本的数据处理方式。应用商店、邮件应用或浏览器中链接的其他无关应用和网站不在本政策范围内。

简而言之：应用没有账号体系、广告、行为分析或应用内购。游戏设置与进度保存在本地，我们没有接收存档数据的游戏服务器。

二、保存在设备上的信息

为了恢复你的游戏体验，应用可能在本地应用存储中保存以下信息：

  • 所选界面语言、音量、音效、操作方式和显示偏好。
  • 所选守夜人与路线、路线或职业解锁状态、最佳成绩以及其他已支持的游戏进度。
  • 在应用记录该状态时，已阅读披露的版本或确认状态。

这些信息仅用于提供和恢复本地应用功能，不构成远程账号画像。当前游戏不会要求你提供姓名、精确位置、通讯录、照片或支付信息。

三、初始设备语言选择

首次启动时，应用会读取 Android 提供的语言偏好，以选择已支持的界面语言。如果首选语言不受支持，应用会使用英文。手动选择语言后，该选择会保存在本地，并在后续启动时优先使用。

语言偏好用于界面展示，核心游戏不会将该偏好传输给开发者。

四、网络使用与远程协议页面

核心玩法不需要网络连接。应用内的隐私政策和服务协议链接指向 GitHub Pages 托管的页面，打开这些页面需要网络；设备或托管服务离线时，页面可能无法访问。

当你主动打开远程协议页面时，浏览器或 WebView 会向 GitHub Pages 发出标准网页请求。GitHub 可能为提供和保护服务而处理技术连接信息，例如 IP 地址、请求的网址、时间以及浏览器或设备请求头。应用不会把你的存档数据附加到这些链接中。

本网站不使用广告、分析脚本、跟踪像素，也不会设置由我们控制的 Cookie。你的浏览器、网络服务提供方和 GitHub Pages 有各自的数据处理规则。

五、第三方服务与外部链接

当前应用未集成广告网络、行为分析服务、支付处理方、社交登录服务或由开发者运营的游戏后端。

GitHub Pages 托管本网站及协议文档。应用商店可能依据其隐私规则处理你浏览、下载、安装或更新应用时的信息。当你选择邮箱链接时，邮件应用及其服务提供方会处理邮件及其中内容。

开发者不出售或出租个人信息。核心游戏不会出于广告或行为画像目的，向开发者或第三方共享个人信息。

六、保留与删除

本地设置与进度会保留在设备上，直到你在 Android 设置中清除应用存储或卸载应用。上述操作会删除应用本地保存的设置、解锁状态、成绩与进度。如需保留设备或应用商店另行提供的备份，请自行确认；游戏本身不提供云存档同步。

应用退出时，正在进行的巡夜不会上传到开发者服务器。GitHub、应用商店或邮件服务提供方独立处理的信息，按照相应服务提供方的规则保留。

七、数据安全

将游戏数据保存在应用本地存储中，可以减少传输这些数据的需要。远程协议页面通过 HTTPS 提供。任何存储或传输方式都无法保证绝对安全，请及时更新设备和操作系统，并使用设备提供的访问保护功能。

八、未成年人隐私

当前应用不会通过账号注册、广告、分析或游戏服务器，故意收集未成年人的个人信息。家长或监护人应在适当情况下指导未成年人使用远程网页链接和邮件功能。如果你认为有人向开发者发送了不必要的个人信息，请联系我们，以便核查并在法律要求时从我们自己的记录中删除。

九、你的选择与隐私权利

你无需创建账号即可体验核心游戏，可以在应用内更改界面语言，可以不打开远程页面或邮件链接，也可以通过 Android 的系统控制删除本地数据。

根据适用法律，对于你主动发送给我们的个人信息（例如支持邮件），你可能享有相应权利。你可以联系我们，请求访问、更正或删除我们自己记录中的信息，但需遵守法定保留义务并完成必要的身份核验。平台或 GitHub 持有的信息，请通过相应服务提供方处理。

十、本政策的更新

当应用功能、托管方式或数据处理方式变化时，我们可能更新本政策。页面顶部的文档版本与生效日期代表当前文本。涉及重要变化时，我们会在应用或本网站的适当位置进行说明。更新后继续使用，适用修订后的政策；适用法律要求其他通知或同意方式的除外。
